Spooky Neighborhood LIVE

The crew moved into a haunted cul-de-sac for Halloween. They carve pumpkins, hand out candy, rake leaves and light graveyard candles. One of them is NOT here for the candy. 👀

  • 🎃 Every $HPEEN buy moves a new crewmate into the neighborhood (max 25, after that buys boost the tasks bar).
  • 😈 Sells make the impostor faster and more likely to sabotage the lights.
  • 🍬 Big buys trigger candy rain or the Pumpkin King parade.
  • 🚨 Bodies get reported, the crew argues, somebody gets yeeted. Tasks bar full = crew wins. Too many ghosts = impostor wins. Then it all restarts.

Trades are read from DexScreener's public data roughly every 45 seconds, so the action can lag a bit behind the chart. Crewmates get silly random names, never wallet addresses. 📺 Stream this on TikTok / X with OBS
  1. In OBS, add a Browser source.
  2. URL: https://hallowpeen.com/live/?obs=1 (add &sound=1 for sound effects, or &demo=1 to rehearse before launch).
  3. Width 1920, height 1080 (for a vertical TikTok canvas, use 1080×1920 and the scene fits the middle, or crop it).
  4. Tick Control audio via OBS if you want the sounds on stream. Leave "Shutdown source when not visible" off so it keeps running.
💬 Chat commands (host / mods)

TikTok and X don't let a website read live chat directly, so commands come in three ways:

  1. Host panel: open https://hallowpeen.com/live/?host=1 for buttons and a command box. In the OBS source, right-click → Interact, then press / or Enter to type a command.
  2. Hotkeys (OBS Interact window focused): Shift+V vent, Shift+M meeting, Shift+S sabotage, Shift+C candy, Shift+D dance, Shift+P parade, Shift+N new crewmate. Tools like TikFinity or Streamer.bot can fire these as keypress actions.
  3. Local WebSocket: add &ws=ws://localhost:PORT. Any local relay that broadcasts !candy as text, or JSON like {"cmd":"!vent","user":"name"}, {"comment":"!dance","nickname":"name"}, or {"name":"Sussy Bob"} (adds a name to the queue), works. Only localhost addresses are accepted.

Commands: !vent (20s cooldown), !meeting (60s), !sabotage (45s), !candy (30s), !dance (15s), !parade (60s), !spawn [name] (8s).

📝 Crewmate names

Names typed into the "Name a crewmate" box get checked for bad words and slurs, length, and wallet-looking strings. On a viewer's own screen the name moves in right away. On the host's screen (?host=1 or ?obs=1) names wait in a queue, and each new crewmate takes the next one. There is no server, so names never leave the browser that typed them. For names that should show up for everyone, add them to the NAMES list at the top of live/sim.js.

🎆 Halloween night finale

At midnight on Oct 31 (viewer's local time), the current round ends and a giant finale round starts with a full 25-crewmate neighborhood, 2 impostors, and fireworks, followed by a "Season 1 complete" screen with stats. Preview it with ?finale=1.
